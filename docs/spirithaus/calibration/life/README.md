# Lifestyle frames

Three delivered lifestyle frames. They live apart from `../hero/` for two reasons.

**They cannot be calibrated.** The `life` slot has `zone: "none"` — no type is laid over
these images in the theme — so there is no quiet zone to measure and the runner reports
them as `-`. That is correct behaviour, not a gap. Their focal entries are recorded for
reference only.

**They would break the hero run.** `life-packing.png` is 2:3 where everything else is
3:2, and a folder with mixed aspects has no single safe zone. The runner refuses to
print one rather than quietly showing the wrong one, which would take the safe zone out
of the hero report as collateral.

| file | subject | shape |
| --- | --- | --- |
| `life-build.jpg` | a hand stirring a mixing glass | 3:2 |
| `life-packing.png` | packing a bottle into a shipping box | **2:3 portrait** |
| `life-sydney.jpg` | a paper carry bag by a window at sunset | 3:2 |

If the theme ever lays type over a lifestyle slot, these move into a calibrated set of
their own — one per aspect, not one folder.
