# CLAUDE.md

## This repository no longer holds the SpiritHaus theme

The Shopify theme that briefly lived on this branch has moved to its own
repository:

    https://github.com/singhajay001/spirithaus-theme   (branch: main)

That repository is what Shopify's GitHub integration syncs. Full history came
across — every commit from the original build is present there. Do not restore
the theme here, and do not connect Shopify to this repository.

This branch is kept only so the move is traceable. It can be deleted.

## What this repository is

`singhajay001/Lakhman` is a general-purpose repository. Its `main` branch
contains a single empty placeholder file, `lakhman-platform`, and has never
contained the theme.

There is no build system, no dependency manifest, no tests and no CI. If you are
asked to work here, establish what the project actually is before writing
anything — do not assume it is the Shopify theme.
