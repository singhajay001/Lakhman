## How to work the sheet

It is sorted A → B → C, and within each tier by price descending, so the most
valuable rows are at the top of each block.

Three columns to fill:

- **In stock? (y/n)** — the one that drives everything. Only "y" rows can be
  photographed.
- **Cost ex GST per bottle** — Tiers A and B.
- **Photo source** — `shoot` if you hold it, `supplier` if you will request
  imagery from the distributor, `na` if you are not ranging it.

Filenames are pre-computed in the same convention as the existing shoot list,
so images drop straight in with no renaming.
