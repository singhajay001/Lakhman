# Collection tagging — 2026-09-25

## The finding that changed the approach

I had planned to add 133 drafts to collections manually. That would have been wrong:
**every collection in this store is a smart collection driven by a tag.**

| Collection | Rule |
|---|---|
| Wine | `TAG = wine` |
| Red / White / Sparkling | `TAG = red` / `white` / `sparkling` |
| Rosé | `TAG = rosé` |
| Champagne | `TAG = champagne` |
| Fortified & Dessert | `TAG = fortified` |
| Fine Wine | `TAG = fine-wine` |
| Australian Made | `TAG = australian` |
| Under $50 | `VARIANT_PRICE < 50` |
| **Specials** | **`IS_PRICE_REDUCED IS SET`** |

So the fix is tagging, which is self-maintaining — a new product with the right tags
lands in the right collections automatically, forever.

**Note on Specials:** it keys off `IS_PRICE_REDUCED`. The compare-at repricing the
owner asked for will populate `/collections/specials` automatically. No extra work.

## An accent trap worth recording

The Rosé collection's rule is `TAG = rosé` — **with the acute accent**. Every product
in the store is tagged `rose` **without** it, and all 16 still appear in the
collection. Shopify matches smart-collection tags accent-insensitively.

Had I "corrected" the tag to `rosé` to match the rule, nothing would have broken —
but had I assumed the opposite and gone looking for a bug, I'd have wasted the time.
Tagged `rose`, matching the store's existing and demonstrably working convention.

## What was done

**140 products tagged** — 139 fine-wine drafts plus one live product. Zero errors.

| Tag | Added to |
|---|---|
| `wine` | 140 |
| `fine-wine` | 139 |
| `to-confirm` | 139 |
| `red` | 84 |
| `australian` | 46 |
| `sparkling` | 27 |
| `white` | 24 |
| `champagne` | 20 |
| `rose` | 6 |
| `fortified` | 3 |

Colour came from the ALM `Group` column for 126 of them. The other 14 had no ALM
match and were resolved by name — the Champagnes (Perrier-Jouët Belle Époque,
Bollinger Blanc de Noirs, Ruinart Blanc de Blancs), the House of Arras sparklings,
the Petaluma Yellow Label trio, Dow's Tawny, Vasse Felix, Château d'Esclans Rock
Angel and Vignoble Dauny Sancerre Rouge.

**`australian` was applied conservatively**, from a 21-producer allowlist. Cloudy Bay
and Greywacke (New Zealand), Dow's (Portugal) and every French and Italian house were
deliberately excluded — putting a Marlborough wine in "Australian Made" is a factual
error on a public page, and a missing tag is cheaper to fix than a wrong one.

### One product treated differently

**Penfolds Koonunga Hill Shiraz Cabernet** was the only *live* product in the store
with no tags at all — so it sat in zero collections and was unreachable by browsing.
It got `wine`, `red`, `australian` but deliberately **not** `fine-wine`: it is a
$14.99 everyday red, not a fine wine. It is also still missing a SKU.

## Verification

Tags confirmed applied by querying tag counts directly:

| Tag | Before | After |
|---|---|---|
| `wine` | 191 | **331** |
| `fine-wine` | 139 | **278** |
| `red` | 60 | **144** |
| `white` | 50 | **74** |

Smart-collection membership recalculates asynchronously in Shopify and was still
catching up at the time of writing — the collection counts lag the tag counts for a
few minutes. The tags are the source of truth and they are correct.
